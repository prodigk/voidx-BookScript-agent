# Phase 8 Next.js 프론트엔드

## 현재 흐름

```text
주제와 방향 입력
→ POST /api/research-jobs
→ 작업 상태 polling
→ Phase 4 후보 도서와 선정 근거 조회
→ 브라우저에서 후보 검토
→ 구성안·대본 생성과 Phase 7 검증
→ 이슈 문단 선택
→ 부분 재작성과 자동 재검증
```

프론트엔드는 원본 Markdown과 SQLite를 직접 읽지 않는다. 모든 데이터는 `NEXT_PUBLIC_API_BASE_URL`에 지정한 로컬 FastAPI의 제한된 응답으로만 받는다.

## 디자인 방향

`DESIGN-airbnb.md`의 흰 캔버스, 넓은 여백, 14~20px radius와 `#ff385c` 포인트를 적용했다. 한국어 본문은 시스템에 설치된 Pretendard 또는 Noto Sans KR을 우선하며, 무거운 대시보드 대신 차분한 에디토리얼 작업실로 구성한다.

대표 패턴은 `Research ribbon`이다. 요청 준비, 책과 근거 탐색, 후보 정리의 현재 단계를 색상뿐 아니라 아이콘과 텍스트로 함께 표시한다.

방향 선택은 핵심 옵션을 먼저 보여주고 `더 보기`로 확장한다. 현재 제공 범위는 다음과 같다.

콘텐츠 형식은 `일반 영상`과 `쇼츠 · 한 권`을 제공한다. 쇼츠는 60초와 1권을 고정하고 후보 선택 시 기존 책을 새 선택으로 교체한다. 구성안에는 생활형 훅, 책 공개, 핵심 통찰, 한 문장 적용의 네 섹션을 표시한다.

- 정서적 진입점: 위로, 위안, 공감, 안도, 호기심, 용기, 희망, 자기이해, 문제의식, 경각심
- 주요 관점: 인문학, 철학, 심리학, 사회학, 관계, 문화, 역사, 윤리, 뇌과학, 교육
- 후반부 확장: 자기이해, 관계 회복, 자기돌봄, 감정 조절, 삶의 의미, 가치 탐색, 일상 성찰, 내면의 변화
- 기본 제외: 커리어, 생산성, 조직관리, 성과 중심

Phase 4 요청 스키마에 맞춰 정서적 진입점은 최대 8개, 주요 관점과 후반부 확장은 합쳐서 최대 8개까지 선택한다.

## 환경 변수

```dotenv
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000
```

백엔드에는 프론트엔드 origin이 허용되어야 한다.

```dotenv
ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```

## 검증 리비전 UI

- 고위험 이슈를 문단 단위로 묶어 원문 대본, 문제와 재작성 제안을 함께 표시한다.
- `unsupported_paraphrase`, `unsupported_causal_claim` 문단은 기본 선택하며 사용자가 개별 해제할 수 있다.
- 선택 문단만 새 실행에 반영하고 `부분 재작성 → 다시 검증 → 결과 확인` 진행 상태를 표시한다.
- 승인 또는 남은 이슈가 있는 새 대본·검증 결과로 작업 공간을 갱신한다.
- 출처 누락, 행 범위, 인용문 변경과 귀속 오류는 자동 재작성 체크박스를 제공하지 않는다.

## 현재 경계

- `insufficient_evidence`는 오류가 아니라 별도의 근거 부족 상태로 표시한다.
- 작업 취소, 일반 작업 재시도와 새로고침 후 작업 공간 복원은 아직 지원하지 않는다.

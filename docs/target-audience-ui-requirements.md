# 타겟 시청자 및 영상 방향 UI 요구사항

## 목적

주제 입력 화면에서 대상 시청자만 선택하는 데 그치지 않고, 대상이 공감할 정서적 진입점과 영상이 확장할 실용 주제를 함께 설정할 수 있어야 한다.

기본 연결 구조:

```text
타겟 시청자
→ 정서적 진입점
→ 주요 관점
→ 확장 주제
→ 제외할 관점
```

## 필수 입력 옵션

- 타겟 시청자: 자유 입력과 프리셋을 모두 지원한다.
- 정서적 진입점: 위로, 위안, 공감, 문제의식, 호기심 등을 복수 선택할 수 있다.
- 주요 관점: 인문학, 철학, 심리학, 사회학, 관계, 문화, 역사, 윤리 등을 복수 선택할 수 있다.
- 확장 주제: 영상 후반부에 연결할 자기이해, 관계 회복, 감정 조절, 삶의 의미, 일상 성찰 등을 선택할 수 있다.
- 제외할 관점: 이번 영상에서 다루지 않을 문맥을 복수 선택할 수 있다.
- 직접 편집: 프리셋 선택 후 모든 옵션을 사용자가 수정할 수 있어야 한다.

## 인문 탐구 프리셋

```yaml
audience_preset: 인문·철학·심리학에 관심 있는 일반 성인
emotional_entry_points:
  - 공감
  - 위안
  - 자기이해
desired_lenses:
  - 인문학
  - 철학
  - 심리학
expansion_topics:
  - 관계 회복
  - 삶의 의미
  - 일상 성찰
excluded_lenses:
  - 커리어
  - 생산성
  - 조직관리
  - 성과 중심
```

권장 영상 흐름:

```text
일상에서 마주하는 감정과 질문
→ 심리적 원인 설명
→ 철학적 관점과 긴장
→ 자기이해와 관계의 재해석
→ 삶의 의미를 남기는 차분한 질문
```

커리어·생산성·조직관리·성과 중심은 새 연구 실행의 기본 제외 관점이다. 동일한 책이라도 인문학·철학·심리학적 근거가 충분하지 않으면 최종 후보에서 제외해야 한다.

## UI 동작 원칙

- 프리셋은 초기값만 제공하며 검색·선택 정책을 숨기지 않는다.
- 선택된 옵션이 도서 후보 랭킹에 어떤 영향을 주는지 표시한다.
- 후보 도서에 주제 적합성, 편집 관점 적합성, 정서 적합성, 제안 역할을 노출한다.
- 제외된 도서는 사용자가 확인하고 다시 포함할 수 있어야 한다.
- 타겟 프리셋을 바꾸면 변경될 옵션을 먼저 보여주고 사용자의 직접 편집값을 임의로 덮어쓰지 않는다.
- 모바일에서는 복수 선택 옵션을 접을 수 있는 섹션이나 drawer로 제공한다.
- 모든 선택지는 label과 keyboard focus를 지원하며 색상만으로 선택 상태를 표현하지 않는다.

## 현재 파이프라인 연결

현재 Phase 4 입력과 바로 연결되는 값:

- `audience` ← 타겟 시청자
- `desired_lenses` ← 주요 관점
- `desired_emotional_effects` ← 정서적 진입점
- `excluded_lenses` ← 제외할 관점

향후 Phase 5에서 추가할 값:

- `audience_preset`
- `emotional_entry_points`
- `expansion_topics`
- `narrative_progression`

`expansion_topics`는 단순 검색 키워드가 아니라 영상 후반부의 서사 역할로 전달되어야 한다.

## Phase 8 구현 시 확인 사항

- DESIGN-airbnb.md의 spacing, typography, color, radius와 interaction token을 사용한다.
- 타겟 프리셋과 세부 옵션을 하나의 거대한 폼으로 노출하지 않는다.
- 선택 결과를 요약하는 읽기 쉬운 문장 또는 카드 미리보기를 제공한다.
- 기존 Phase 4 API 입력과 프론트엔드 타입을 일치시킨다.
- 인문 탐구 프리셋의 E2E 테스트에서 `일상 질문 → 인문학·철학·심리학 → 자기이해·관계·삶의 의미` 방향과 기본 제외 관점이 요청 payload에 보존되는지 검증한다.

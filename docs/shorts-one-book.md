# 한 권 쇼츠 시나리오

## 목표

사용자가 입력한 주제와 가장 직접적으로 연결되는 로컬 도서 한 권을 선정하고, 근거가 확인된 핵심 통찰 하나를 60초 한국어 쇼츠 시나리오로 만든다. 일반 영상과 동일하게 검색·근거 큐레이션·출처 검증을 거치며, 책 전체를 요약하거나 근거가 없는 효능을 약속하지 않는다.

## 사용자 흐름

```text
주제 입력 · 쇼츠 선택
→ 후보 도서 검색과 근거 수집
→ 한 권 검토·확정
→ 60초 4단 구성안
→ 출처 연결 대본
→ 인용·요약·귀속 검증
```

## 고정 시나리오

| 순서 | 기능 | 역할 | 권장 시간 |
|---|---|---|---|
| 1 | 생활형 훅 | 시청자가 겪는 짧은 상황이나 질문으로 시작 | 5~10초 |
| 2 | 책 공개 | `『책 제목』`과 저자를 한 번 명시하고 선정 이유 연결 | 8~12초 |
| 3 | 핵심 통찰 | 근거가 있는 관점 하나만 설명 | 25~35초 |
| 4 | 한 문장 적용·여운 | 오늘 해볼 작은 선택 또는 질문으로 끝맺음 | 8~15초 |

생성 결과는 정확히 4개 섹션, 총 60초이며 선택 도서는 정확히 1권이어야 한다. 책 제목과 저자는 `book_intro` 섹션에서만 말할 수 있고, 화면 직접 인용은 로컬 원문 대조를 통과한 경우 최대 1개만 허용한다.

## 제품·기술 규칙

- 연구 요청은 `content_format: "shorts"`를 사용하며 서버가 `duration_minutes=1`, `target_book_count=1`로 정규화한다.
- 후보를 바꾸면 기존 선택에 추가하지 않고 새 한 권으로 교체한다.
- 선택 리비전은 후보 포함 여부와 신뢰도 0.5 이상 근거를 검사한다.
- 구성안은 `hook → book_intro → book_perspective → conclusion` 순서를 강제한다.
- 대본은 각 섹션의 book/evidence 계약, 목표 분량, 제목·저자 노출 위치를 로컬에서 검증한다.
- `script_with_sources.md`, `script.md`, `citations.json`, `validation_report.md` 등 기존 불변 산출물 구조를 그대로 사용한다.

## 범위 밖

- 한 영상에서 두 권 이상 비교
- 60초를 넘는 쇼츠 길이 선택
- 실제 음성 합성 결과를 이용한 러닝타임 측정
- 9:16 Remotion 렌더링과 자막·영상 자산 자동 배치

마지막 항목은 승인된 쇼츠 대본을 입력으로 받는 별도 영상 렌더링 단계로 확장한다.
